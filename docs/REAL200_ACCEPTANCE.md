# 真实财报200轮验收说明

本轮只使用10家真实公司的117份原始财报，合成演示数据不进入题库、标准答案、截图或新成绩。本轮公开范围为代码、报告、题库和测试摘要，不上传117份原件及整批来源资产。

## 固定范围与评分

题库为120道独立问题及20组四轮对话，共200轮。达标线为170/200，最多两轮共性修复。分项统计经典类别、支持范围内完成率、80轮对话以及20组整组成功率。固定题库重跑是回归验收，不称全新盲测。

标准答案在运行前生成并固定：读取真实PDF原页和行区域，核对原值、单位及十进制归一化；派生值使用独立Decimal公式。程序评分不导入生产规划器或执行器。概念、原因解释和事实含义另外记录原文复核，未复核不算最终通过。助手核对不写成成员已经人工审核。

有充分条件却拒答、遗漏目标、空回答、超时和服务异常计失败。只有题库事先注明应澄清、不支持或确实缺证据，才允许对应处理通过。错数、错口径、编造出处和越权单列，不能被整体分数掩盖。对话使用真实保存的上一轮状态，不注入预制历史，不替换失败回答。

## 运行入口

先准备并验收当前真实事实和索引版本，确保只读数据库账号具有v3查询权限。环境凭据留在私有配置；测试数据库、任务存储和消息空间隔离。测试账号配额提高仅用于连续验收，不改变生产默认配额。

```text
python eval/build_real200.py --audit <已验收真实版本目录> --output <新题库文件>
python eval/real200_acceptance.py --suite <固定题库> --audit <真实版本目录> --oracle <标准文件> --prepare
python eval/real200_acceptance.py --suite <固定题库> --audit <真实版本目录> --oracle <标准文件> --base <Java地址> --output <新运行目录>
```

题库已有时构建器拒绝覆盖。已有运行不能覆盖；同一版本恢复时只执行尚未提交的题目，并使用已经保存的会话。程序执行异常留在记录中，不重试到成功替换。若进程在任务提交后意外退出，先根据客户端请求ID核对服务端任务；不能盲目重发该题或删除已经执行的记录。

冻结记录包括代码摘要、题库摘要、标准文件摘要、数据版本、索引集合、模型名称与摘要、上下文与采样设置及评测日期。运行中的生产代码或题库变化使冻结条件失效。评分器自身的问题必须说明修正依据并保留原评分，不能因模型失败改变标准答案。

## 结果与公开边界

每次运行保存完整记录、摘要、分项错误和耗时。最终验收报告从同一次完整200轮产生，不拼接多个版本的成功题。原页标准、本机原件和私有任务记录保留在本机；公开时另做脱敏与具体授权检查，不把账号密码、内部令牌或历史私人会话混入资料。
