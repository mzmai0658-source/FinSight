# 财报资料与原页维护

公开初始化 [demo-seed](DEMO.md) 生成十五份原创虚构PDF与v3报告目录，经来源检查后发布。聊天原页通过登记资产或公司/报告期资源入口打开；缓存与别名不能替代内容摘要和真实物理页。

真实资料导入是可选维护流程，须自行取得合法原件与OCR访问权。先登记文件身份/版本，再审计候选事实、范围、单位及单元格证据，建立独立索引并验收发布。导入失败不切当前数据指针，不把没有识别出的值填零。具体任务/数据版本见 [v3说明](FINSIGHT_V3_API.md)。

当前真实公开覆盖仅提供 [只读摘要](evidence/real-readonly-check.json)，完整原件与审核清单留本机。历史资料库批量导入数量不代表当前数字问答全部支持范围，旧导入报告不随本包混入最终成绩。
