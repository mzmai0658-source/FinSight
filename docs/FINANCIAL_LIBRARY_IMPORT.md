# 财报资料与原页维护

当前使用 10 家公司、117 份真实财报及其规范事实、来源和 BGE 索引。首次准备真实资料按[安装说明](REAL_DATA_INSTALL.md)，已有环境沿用当前发布版本。历史 `demo-seed` 和虚构 PDF 不作为当前资料库或真实验收入口。

聊天原页通过登记资产或公司/报告期资源入口打开，缓存与别名不能替代内容摘要和真实物理页。新原件先取得合法使用权并登记文件身份/版本，再审计候选事实、范围、单位及单元格证据，建立独立索引并验收发布。失败不切当前指针，不把没有识别出的值填零。OCR 复用与重建边界见[缓存说明](OCR_CACHE_USAGE.md)。

生成任务统一使用 DeepSeek 云端服务，BGE embedding 仍在本机。仅迁移生成模型不改变已有原件、事实、向量空间或发布版本，不需要重新导入。任务、数据版本与来源网关见[v3 说明](FINSIGHT_V3_API.md)。

真实原件与完整审核资产留在本机，资料包的公开分享范围和下载核对另行确认。历史资料库导入数量不代表当前问答支持范围，旧验收成绩不能作为云端模型成绩。
