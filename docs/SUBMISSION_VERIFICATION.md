```powershell
python -c "import json,hashlib,pathlib; r=pathlib.Path('.'); m=json.loads((r/'RELEASE_MANIFEST.json').read_text(encoding='utf-8')); bad=[n for n,h in m['files'].items() if not (r/n).is_file() or hashlib.sha256((r/n).read_bytes()).hexdigest()!=h]; print('OK' if not bad else bad); raise SystemExit(bool(bad))"

```
