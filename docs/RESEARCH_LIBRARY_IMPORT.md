# 可选研报资料维护

研报不是当前运行前置依赖。当前经营解释来自 10 家公司、117 份真实财报对应的 OCR 叙述、原页及已核验事实；原因结论需要同公司、同期间与对应指标的证据，不能借无关研报补齐缺报告。生成任务调用 DeepSeek 云端，BGE 检索保持本机执行；历史十五份虚构年度 PDF 不作为当前叙述来源。

未来导入有权使用的机构研报，应记录内容摘要、原始版本、身份及物理页，清理展示用文字/HTML，区分报告观点与经核验财务事实。公开可访问不等于可以再分发；未确认授权的原件不放进源码提交包。云端请求涉及的证据内容和服务条款由使用者按实际部署核对。

历史本机研报批量导入记录归档保存，本轮未重新验收完整研报库或用户体验。第三方与开放边界见[资源清单](THIRD_PARTY.md)，当前参数和服务要求见[部署说明](DEPLOYMENT.md)。
