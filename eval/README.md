# 评测入口与证据

当前模型为DeepSeek Flash，当前试验资料为119份真实报告、7607事实和21437云端向量片段。最新64+24轮正式记录分别完整处理46和18轮；详见[结果摘要](../docs/validation/RESULTS.md)。记录首次输出，环境失败不剔除，概念/原因独立复核，不能从模型自报通过评分。

本目录保留供测试引用的历史评分与回放工具。200/264/324/300及本地模型入口均有各自数据和版本前提，不等同本包能直接复跑的最新成绩，不合并分数。部分历史工具依赖本机封存证据，不应在空目录盲跑。当前复现和录屏从[安装说明](../docs/INSTALL_CURRENT.md)与[演示指南](../docs/VIDEO_GUIDE.md)进入。

正式多轮必须经Java/SSE使用实际保存状态，冻结问题、预期、数据与源码；不注入答案或正确历史。正确任务条件重放只用于诊断，不是模型自主成绩。完整付费原文、PDF/OCR和账号留在本地验收附件；源码包仅含可公开的测试工具和脱敏汇总。模拟测试与真实服务检查分开记录。
