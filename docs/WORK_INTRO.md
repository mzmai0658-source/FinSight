# 作品名称与简介

作品名称：FinSight财报证据助手

方向：开源赋能的AI应用创新

简介：财报查询常遇到指标口径混淆、跨期比较困难、答案难以回查原文等问题。FinSight将自然语言整理为统一请求，以本地Qwen理解意图，由程序执行只读查询、精确计算与来源核验，提供表格、图表和PDF原页证据。系统支持连续对话条件修改、任务取消与刷新恢复，采用Python、Java、Vue和开源组件实现。公开演示包含五家虚构公司的十五份年度报告，源码、生成定义、运行指南与验收工具均可复现。最终实测成绩与已知限制另附，不把模型理解或检索相似度当作财务正确性证明。
