# 当前自主实现与验证边界

自研内容是统一请求与逐条件修改、Decimal确定性执行、事实与PDF原页绑定、分项核验、版本化数据发布、持久任务取消与恢复以及前端证据交互。第三方LangGraph/Ollama/Qwen/BGE、数据库和网页框架在资源清单披露，不写成原创模型或算法。

相关方法参考FinGLM的结构化查询、TAT-LLM的数值程序执行、ConvFinQA的连续事实引用。当前没有复制其训练权重、数据或实现；比较是方法与实现边界说明，不是与其公开基准分数的公平性能对照。

当前工程验证为公开虚构数据：五家公司、十五份报告、240事实和30叙述片段，来源、范围、单位和兼容投影经同一门槛检查。真实数据的当前只读覆盖另附，不把虚构测试推广为真实财报全范围正确率。

冻结Qwen20轮结果18/20，经典8/8、易错3/4、对话7/8，完整对话组1/2成功。E04复合缺证据问题未交付可靠部分，B3正负前提纠正未完成；均未发布错误数字。程序核验减少可见错答，不证明已覆盖所有自然语言。
