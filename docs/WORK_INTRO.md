# 作品名称与简介

作品名称：FinSight财报证据助手

方向：开源赋能的AI应用创新

简介：财报查询常遇到口径混淆、跨期比较和原文回查困难。FinSight用本地Qwen理解统一请求，由只读查询、Decimal计算与来源核验提供表格、图表和PDF原页，支持连续修改条件、取消与刷新恢复。系统采用Python、Java、Vue及开源组件。本轮使用10家公司117份真实财报，完成120道独立问题与20组四轮对话；固定回归成绩和限制另附。代码、类型、评测工具及技术报告构成开放成果，不以模型自评代替财务正确性。
